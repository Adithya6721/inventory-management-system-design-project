# AetherStock / EfficientStock LaTeX report

## Files

- `AetherStock_Project_Report.tex`: complete, editable report source.
- `images/`: eight cropped PNG screenshots from the current PDF, at 300 DPI.
- `images/README.md`: image names and source PDF page numbers.
- `images/manifest.json`: screenshot dimensions, crop coordinates and source hash.

The cover carries over **EfficientStock**, the five names and register numbers
from the edited PDF. The body retains **AetherStock**, as in that PDF. Edit
`\CoverProjectName`, `\ReportProjectName`, and `\TeamRows` near the top of the
`.tex` file to update these details.

Paragraphs, formulas, tables, captions and references are editable LaTeX. The
logo, architecture diagrams and graphs are attached through `\includegraphics`.
Page numbers, contents, figure list, and table/figure numbering are generated by
LaTeX. Explicit page breaks follow the report's original section layout.

## Overleaf

1. Choose **New Project → Upload Project**.
2. Upload `AetherStock_LaTeX.zip`.
3. Set the main document to `AetherStock_Project_Report.tex` and the compiler to
   **pdfLaTeX**.
4. Recompile. The image folder is already connected in the source.

The ZIP contains all required content; it does not need Python, the application,
the benchmark folders, or the original PDF to compile.

## Local compilation

With a TeX Live or MiKTeX installation, run from the folder containing the `.tex`
file and `images/`:

```powershell
New-Item -ItemType Directory -Force latex-build
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=latex-build AetherStock_Project_Report.tex
pdflatex -interaction=nonstopmode -halt-on-error -output-directory=latex-build AetherStock_Project_Report.tex
```

Two runs populate the linked contents and figure list. The compiled report is
`latex-build/AetherStock_Project_Report.pdf`.

## Attach an image elsewhere

```latex
\usepackage{graphicx}
\graphicspath{{images/}}

% Inside the document:
\begin{figure}[htbp]
  \centering
  \includegraphics[width=\textwidth]{architecture.png}
  \caption{Implemented inventory-system architecture.}
  \label{fig:architecture}
\end{figure}
```

## Re-export from the repository

```powershell
python docs/report/export_latex.py
```

The exporter uses the existing report's structured content and reads the current
PDF for cover details and figure screenshots. It requires Python with ReportLab,
Matplotlib, Pillow, pdfplumber and pypdfium2. Re-exporting replaces the generated
`.tex`, its images and the ZIP, so make subsequent content edits in your chosen
LaTeX working copy.
